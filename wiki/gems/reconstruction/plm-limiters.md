# PLM Limiters

> Piecewise linear reconstruction wrappers (`ghl_minmod_reconstruction`, `ghl_mc_reconstruction`, `ghl_superbee_reconstruction`) and shared slope-limiter helpers. · Status: confirmed
> Up: [Reconstruction](index.md)

## Summary

`GRHayL/Reconstruction/PLM/` provides parameter-free 4-point left-face piecewise-linear reconstruction routines built from shared slope helpers (`ghl_minmod` and `ghl_maxmod`), directly tested over interior stencils by `Unit_Tests/unit_test_PLM_reconstruction.c`.

## Detail

### Public PLM Routines And Shared Limiter Helpers

Each public routine accepts `const double U[4]` (`i-2 .. i+1` around face `i-1/2`; see [Face And Stencil Conventions](face-and-stencil-conventions.md)) plus `Ur` and `Ul` outputs, with fixed source coefficients and no runtime parameter struct:

| Function | Source file | Slope-limiting rule |
| --- | --- | --- |
| `ghl_minmod_reconstruction` | `PLM/minmod_reconstruction.c` | Applies `ghl_minmod` to adjacent one-sided differences. (Ev: `minmod_reconstruction.c::ghl_minmod_reconstruction`) |
| `ghl_mc_reconstruction` | `PLM/mc_reconstruction.c` | Applies repeated `ghl_minmod` over centered and `2x` one-sided slopes. (Ev: `mc_reconstruction.c::ghl_mc_reconstruction`) |
| `ghl_superbee_reconstruction` | `PLM/superbee_reconstruction.c` | Combines `ghl_minmod` candidates with `ghl_maxmod`. (Ev: `superbee_reconstruction.c::ghl_superbee_reconstruction`) |
| `ghl_minmod` / `ghl_maxmod` | `PLM/minmod.c`, `PLM/maxmod.c` | Shared slope helpers; modifying either impacts multiple PLM routines. (Ev: `minmod.c::ghl_minmod`) |

### Build Membership And Test Coverage

`GRHayL/Reconstruction/PLM/make.code.defn` compiles every C file above. `Unit_Tests/unit_test_PLM_reconstruction.c` dispatches each public PLM wrapper against `PLM_reconstruction_{input,output,output_pert}.bin` (generated by `unit_test_data_PLM_reconstruction.c`) over valid interior indices `2 <= index < arraylength - 1` (boundary slots hold zero placeholders ignored by replay) and exits via `ghl_error` on mismatch. Neither `ghl_minmod` nor `ghl_maxmod` has a standalone unit test outside wrapper coverage, and the PLM test does not cover PPM.

Evidence (descriptive behavior): `GRHayL/Reconstruction/PLM/make.code.defn`; corroboration: `unit_test_PLM_reconstruction.c`.
