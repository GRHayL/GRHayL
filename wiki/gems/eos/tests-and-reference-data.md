# EOS Tests And Reference Data

> Direct EOS unit tests, CompOSE Python/C integration tests, helper-only files, sample tables, no-HDF5 behavior, and EOS coverage gaps. · Status: confirmed
> Up: [Equation Of State (EOS)](index.md)

## Summary

Direct EOS validation spans `unit_test_piecewise_polytrope.c` (hybrid), `unit_test_tabulated_eos.c` (analytic `simple_table.h5`), `unit_test_tabulated_eos_compose.c` + `Unit_Tests/compose/*.py` (CompOSE converter & runtime integration), and `unit_test_code_error.c` (EOS/HDF5/beta-equilibrium error keys). Malformed table dimensions/axes, final-state finiteness rejection, and invalid derived enthalpy rejection remain direct coverage gaps.

## Detail

### Direct EOS Tests And CompOSE Integration

- **`unit_test_piecewise_polytrope.c`:** verifies four-piece `K_ppoly`, `eps_integ_const`, and `p_ppoly` transitions against adjacent-piece formulas, a one-piece sentinel, and an exact-extent two-piece case; does not test invalid input errors.
- **`unit_test_tabulated_eos.c` (HDF5-only):** loads `simple_table.h5` (generated by `Unit_Tests/sample_table/generate_simple_table.py` or downloaded from `TestData`), validating dimensions, `energy_shift`, analytic quantities (`tabulated_eos_unit_test_helpers.c`), direct `(rho, Y_e, T)` and `eps`/`P`/`S` wrappers, `ghl_compute_h_and_cs2`, selected clamps, and beta-equilibrium helpers.
- **`unit_test_tabulated_eos_compose.c` & `Unit_Tests/compose/`:** CI (`compose-regularized-eos` in Ubuntu GCC) runs every `Unit_Tests/compose/test_*.py` module that `unittest discover` selects under `coverage run --branch --source=tools/compose` with `coverage report --fail-under=100` using an asymmetric synthetic CompOSE input and feeds the converted file into `unit_test_tabulated_eos_compose.c`, which verifies all 19 fields at every node, storage-space interpolation and `eps`/`P`/`S`/`h` inversions, the six-output leakage wrapper, no-fallback Palenzuela recovery, analytic speed/flux/source goldens, implementation-derived combined-leakage regression goldens, and cleanup (CI runs the synthetic table; full SRO-141 replay is manual).
- **`unit_test_code_error.c`:** covers simple/hybrid/tabulated setup, interpolation bounds, too-many-variable calls, malformed `test.h5` reads, invalid EOS/table types, beta-equilibrium bracketing, key `85` (poisoned fresh struct on missing `grhayl_nn_c2p`), and keys `89`–`90` (tabulated Newman1D/Palenzuela1D `ghl_error_table_bisection`). HDF5-only keys skip under `GHL_DISABLE_HDF5`.

Evidence (descriptive behavior): `unit_test_tabulated_eos.c`; corroboration: `unit_test_tabulated_eos_compose.c` and `unit_test_piecewise_polytrope.c`.

### Helper Files, Sample Tables, And Coverage Gaps

- **Helper-only files:** `Unit_Tests/tabulated_eos_unit_test_helpers.c` supplies analytic table reference values for `unit_test_tabulated_eos.c`. `Unit_Tests/test_compute_h_and_cs2.c` is a synthetic LS220-scale callback shared by tabulated flux replay/generation that never reads the EOS table.
- **Sample tables:** see [HDF5 Sample Tables](../../tests/hdf5-sample-tables.md) for the checked-in reduced Hempel SFHo file, `table_info.txt` (ignore its machine-local absolute paths), `generate_simple_table.py`, and downloaded `simple_table.h5`/`LS220`/`SLy4` tables.
- **Coverage gaps & dependent impact tests:** No direct test covers malformed table dimensions/axes, tabulated final-state finiteness rejection, invalid derived enthalpy rejection, or invalid piecewise-polytrope `neos`/ordering/gamma errors. `unit_test_grhayl_core_test_suite.c` comments out its tabulated atmosphere block; dependent tabulated tests live in Con2Prim, Neutrinos, and Flux_Source test leaves.
