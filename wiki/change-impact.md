# Change Impact

Repo ground truth: [GRHayL/](../GRHayL), [GRHayL/include/](../GRHayL/include), [docs/raw/](../docs/raw), [Doxyfile](../Doxyfile),
[.github/](../.github), [Unit_Tests/](../Unit_Tests), [implementations/GRHayLib/](../implementations/GRHayLib), [configure](../configure), and
[.github/run_tests.sh](../.github/run_tests.sh).

Interpret checks by evidence class. `make tests` and `make datagen` compile/link
selected binaries only; they do not execute tests or generators. A named unit
test below means build it, obtain its source-declared prerequisites/fixtures,
then execute it. Workflow presence proves configured intent, not a past
successful run. Keep configuration, compilation, install, consumer link, and
runtime results distinct. Select checks by affected behavior and reuse valid
prior evidence under [the execution contract](../AGENTS.md#agent-execution-contract);
this map does not require unrelated suites for every edit. Use disposable trees
for commands that write build products or fixtures. Adding or expanding tests,
assertions, fixtures, generators, or CI test executions requires explicit
permission for that specific change.
