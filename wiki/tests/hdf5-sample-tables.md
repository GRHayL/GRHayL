# HDF5 Sample Tables

> Checked-in, generated, and downloaded HDF5 EOS tables used across `Unit_Tests/`, their callers, and `--disable-hdf5` build effects. · Status: confirmed
> Up: [Tests](index.md)

## Summary

HDF5 EOS tables used by `Unit_Tests/` drivers fall into three classes: the analytic `simple_table.h5` (generated by `generate_simple_table.py` or fetched from `GRHayL/TestData`), which `.github/run_tests.sh` and the workflows supply to the tabulated EOS test; the downloaded StellarCollapse `LS220` and `SLy4` archives, which they select for the tabulated Flux_Source, Con2Prim, Neutrinos, and expected-error tests; and the checked-in reduced Hempel SFHo sample in `Unit_Tests/sample_table/`, which neither selects. The test-caller table below maps each driver using those tables to its runner/CI selection and manual table-path argument where one exists; in CI, the CompOSE integration test instead reads a converted synthetic CompOSE table ([CompOSE Callback](../gems/neutrinos/compose-eos-leakage-callback.md)). `configure --disable-hdf5` excludes table-dependent test binaries while retaining table-free NN and NRPyLeakage tests.

## Detail

### Table Inventory And Provenance

- **Checked-in reduced Hempel SFHo table:** `Unit_Tests/sample_table/Hempel_SFHoEOS_rho222_temp180_ye60_version_1.1_20120817_simple.h5` is a repository sample table (not used by default `.github/run_tests.sh`). Its companion `table_info.txt` records dimensions/ranges alongside nonportable absolute paths from the machine that built it—never copy those paths into docs.
- **Generated / downloaded `simple_table.h5`:** `Unit_Tests/sample_table/generate_simple_table.py` (requiring `numpy` and `h5py`) creates an analytic `N_rho = 7`, `N_T = 5`, `N_Y_e = 3` table matched by `tabulated_eos_unit_test_helpers.c`. Workflows download `EOS/simple_table.h5` from `TestData` `main`, whereas `.github/run_tests.sh` uses `.github/et-legacy-testdata-ref`.
- **Downloaded StellarCollapse `LS220` & `SLy4`:** `.github/run_tests.sh` and workflows download `LS220_234r_136t_50y_analmu_20091212_SVNr26.h5.bz2` and `SLy4_3335_rho391_temp163_ye66.h5.bz2` from `stellarcollapse.org/EOS/` and decompress them into repository root. Before NN-enabled tabulated Con2Prim replay, scripts run `pyghl append SLy4_3335_rho391_temp163_ye66.h5`.

Evidence (descriptive behavior): `generate_simple_table.py::N_rho`; corroboration: `Hempel_SFHoEOS_rho222_temp180_ye60_version_1.1_20120817_simple.h5` and `table_info.txt`.

### Test Callers And No-HDF5 Build Effects

| Test driver | Table input & role |
| --- | --- |
| `unit_test_tabulated_eos.c` | CLI table path (`simple_table.h5` in runner/CI; the analytic checks require that table); checks dimensions, `energy_shift`, analytic quantities (`tabulated_eos_unit_test_helpers.c`), interpolators, `ghl_compute_h_and_cs2`, and beta-equilibrium helpers. (Ev: `unit_test_tabulated_eos.c`) |
| `unit_test_tabulated_flux.c` | Hard-codes `LS220_234r_136t_50y_analmu_20091212_SVNr26.h5` while substituting synthetic `test_compute_h_and_cs2.c` (does not query table sound speed). (Ev: `unit_test_tabulated_flux.c`) |
| `unit_test_con2prim_tabulated.c` & `unit_test_con2prim_debug.c` | CLI table path (`SLy4` in runner/CI after `pyghl append`, key `1` tests NN disabled and enabled); debug binary is manual-only. (Ev: `unit_test_con2prim_tabulated.c`) |
| `unit_test_nrpyleakage_{optically_thin_gas,constant_density_sphere,luminosities}.c` | CLI `SLy4` table + key `0`/`1` via `nrpyleakage_main.h`; `physics` and `classifier_fallback` take no table. (Ev: `nrpyleakage_main.h`) |
| `unit_test_code_error.c` | Uses `SLy4` (without `grhayl_nn_c2p` for key `85`) for tabulated setup/bound/bisection keys and temporary or missing `test.h5` for keys `34`–`60`, `73`–`74`. (Ev: `unit_test_code_error.c::test.h5`) |
| `unit_test_c2p_nn_guess.c` | Creates and removes its own private temporary HDF5 model files in HDF5 mode (no external table); skips temp setup under `GHL_DISABLE_HDF5`. (Ev: `unit_test_c2p_nn_guess.c`) |

`./configure --disable-hdf5` applies the source, test, and data-generator filters defined in [Build And Configure](../architecture/build-and-configure.md#hdf5-detection-and---disable-hdf5-filtering).
